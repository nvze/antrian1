# 🎯 Queueing Theory Calculator

Web aplikasi untuk menyelesaikan persoalan **Teori Antrean** (Operation Research).

## ✨ Fitur
- **M/M/1** — Single server
- **M/M/c** — Multi server (Erlang C)
- **M/M/1/K** — Kapasitas terbatas (blocking)
- **M/G/1** — Waktu layanan umum (Pollaczek-Khinchine)
- **M/D/1** — Waktu layanan konstan
- **Analisis Biaya** — Waiting cost vs server cost
- **Perbandingan model** M/M/1 vs M/D/1 vs M/G/1

## 🚀 Cara Menjalankan Lokal

```bash
git clone https://github.com/USERNAME/queueing-calculator.git
